PUBLICAÇÃO — JORGE FELIPPE NETO

Endereço previsto:
https://fedconsultancy.com.br/jorgefelippeneto

Na Locaweb/FileZilla:
1. Abra public_html
2. Crie a pasta jorgefelippeneto
3. Envie para dentro dela:
   - index.html
   - acervo.html
   - pasta assets (completa)

A estrutura deve ficar:
public_html/jorgefelippeneto/index.html
public_html/jorgefelippeneto/acervo.html
public_html/jorgefelippeneto/assets/images/...

Observação: os conteúdos do acervo ainda apontam para as publicações originais em jorgefelippeneto.com.br.
